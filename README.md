# 📱 Gestão de Alunos - PWA (Front-end)

Aplicação web progressiva (PWA) desenvolvida para a **UC15**, focada na gestão de alunos, consulta de notas e atribuição de módulos. O sistema é totalmente integrado a um back-end Strapi hospedado na nuvem.

---

## 🚀 Funcionalidades

- **📱 Funcionalidade PWA:** Instalável em dispositivos móveis e desktop com suporte a execução standalone (estilo app nativo).
- **🎓 Gestão de Alunos:** Visualização em grid, busca por nome e edição rápida de notas.
- **🖼️ Mídia na Nuvem:** Renderização de avatares e imagens integradas ao Cloudinary.
- **🔐 Autenticação:** Rotas protegidas via consumo de tokens JWT.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** [Next.js 16](https://nextjs.org/) (App Router, TypeScript)
- **Estilização:** CSS Modules
- **PWA:** `@ducanh2912/next-pwa` (Service Worker e Manifest)
- **API Back-end:** Strapi v5 (Hospedado no Render)
- **Armazenamento de Mídia:** Cloudinary
